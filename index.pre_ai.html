Pac-Man Browser Port

This is a JavaScript port of the supplied Unity project. The maze, scoring, ghost state timing, pellets, power pellets, tunnel teleporters, lives, and round resets follow the professor's base project.

Controls: Arrow keys or WASD. Space stops Pac-Man. P pauses.

For later AI work, the running game exposes window.pacmanGame, including getState(), setAgent(fn), clearAgent(), restart(), pause(), and resume().
