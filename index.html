This version is fully AI-controlled. Choose Level 1 or Level 2 in the Start Level menu, then press Start AI. Pac-Man cannot be controlled with the keyboard. If you start on Level 1, clearing it still advances automatically to Level 2: Crossroads. The −/+ controls change playback speed only (0.5× to 4×).
